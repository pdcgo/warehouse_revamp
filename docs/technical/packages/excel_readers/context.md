# Excel Readers

## General.
1. for tiktok sample live in `./examples/settlement_samples/tiktok/*`
2. for shopee sample live in `./examples/settlement_samples/shopee/*`
3. package live in `./backend/pkgs/san_excel_readers/*`
4. every platform implementation live in `./backend/pkgs/san_excel_readers/[platform].go`
5. every platform implementation test live in `./backend/pkgs/san_excel_readers/[platform]_test.go`

## Responsbility
1. Provide golang library to parsing exported settlement report from excel that generated by platforms.
2. Supported Platform are:
    - Shopee
    - Tiktok

### Shopee Contract
```go

type ShopeeSettlementItem struct {
    At              time.Time               // Column "Tanggal Transaksi"
    TransactionType string                  // Column "Tipe Transaksi"
    Description     string                  // Column "Deskripsi"
    OrderRefID      string                  // Column "No. Pesanan"
    Amount          float64                 // Column "Jumlah"
    LastBalance     float64                 // Column "Saldo Akhir"
}

func (s *ShopeeSettlementItem) GenerateUniqueID() (string, error) {
    // md5hash of (json serialise of s)
}

func (s *ShopeeSettlementItem) SettlementType() (SettlementType, error) {
    ...
}


type ShopeeSettlementDocument interface {
    GetShopUsername() (string, error)  // that exists in "Username (Penjual)
    GetItems([]*ShopeeSettlementItem, error)
    ...
}

func NewShopeeSettlementDocument(r io.Reader) (ShopeeSettlementDocument, error)

```
#### How We Parsing `SettlementType`
| Settlement Type | `TransactionType` |
|-----------------|-------------------|
| `withdrawal` | Penarikan Dana |
| `fund` | Penghasilan dari Pesanan |
| `marketplace_adjustment` | Penyesuaian |
