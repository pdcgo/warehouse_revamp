# Acceptance — balance

context ([context.md](../../business/balance/context.md)); the acceptances split it by what a person does, as
inventory's are. What posts to a balance (the warehouse fee, a product fee, a COD fee, a return's courier charge) is
checked in the feature it comes from. Rules: [guide.md](../guide.md).
